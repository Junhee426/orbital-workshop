# v0.1 검증 기록

검증일: 2026-09-25

## 환경

- Node.js 24.19.0, Python 3 실행 환경
- Playwright 1.62.1과 Chromium 153의 headless 실행
- WebGL 렌더링: SwiftShader 소프트웨어 렌더러
- 데스크톱 화면: 1440 × 960
- 모바일 에뮬레이션: 430 × 932, 터치 입력 활성화

| 서버 | Python 구문 검사 | 통과 |

브라우저 전체 임무 검사는 실제 키·마우스 입력으로 진행했다. 시험용 자동 조종은 읽기 전용 상태 정보로 다음 키 입력을 정했고, 실행 중 시뮬레이션 위치나 임무 단계를 직접 변경하지 않았다. 모바일 정비 화면 검사는 별도의 정상 저장 체크포인트에서 시작해 부품 선택·토크 입력·작업 완료를 확인했다.

검사 중 발견한 부품 표식의 클릭 시 위치 이동 문제를 수정한 뒤 전체 임무 검사를 재실행했다. 모바일 계기판의 위성 가림 문제는 상단 가로 배치와 모바일 카메라 수정으로 해결하고 해당 화면과 조작을 다시 확인했다.

## 검증의 경계

- 실제 iPhone·Android 기기 및 각 제조사 GPU에서의 성능은 측정하지 않았다.
- 실제 Chrome·Edge·Firefox·Safari 전체 버전 조합을 시험한 것은 아니다.
- 플레이 시간 10분은 최초 설계의 목표이며 사람을 대상으로 한 플레이타임·재미 검증은 아직 하지 않았다.
- Render 구성은 공식 Blueprint 필드에 맞춰 작성했으나 실제 배포는 수행하지 않았다.
- 물리 모델은 게임용 근사이며 우주 임무의 공학적 검증에 사용하지 않는다.

화면 예시는 `docs/images`에 포함한다. 전체 브라우저 검사는 `tests/e2e.mjs`, 상태·비행 검사는 `tests/mission.test.mjs`로 재실행할 수 있다.
