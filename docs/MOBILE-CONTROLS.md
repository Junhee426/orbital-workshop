# 지상 운송: 모바일 조작 개선

## 참고한 공개 개발 자료

- [Diablo Immortal PC 개발기](https://news.blizzard.com/en-us/article/23797159/making-diablo-immortal-for-pc): 모바일에서 이동하면서 행동하는 조작, 플랫폼에 맞춘 HUD 크기 조정.
- [Diablo Immortal 접근성](https://news.blizzard.com/en-gb/article/23805083/making-a-game-for-everyonediablo-immortals-accessibility-features): 편안한 모바일 조작을 위한 행동 버튼 위치 조정.
- [Albion Online Queen Patch 11 모바일 업데이트](https://forum.albiononline.com/index.php/Thread/128104-Queen-Patch-11-Mobile-Update/): 가상 조이스틱과 모바일 HUD 개선. 공식 포럼의 검색에 노출된 업데이트 개요를 참고했으며 본문은 접근 제한으로 확인하지 못했습니다.
- [Minecraft 조작 방식 문서](https://learn.microsoft.com/en-us/minecraft/creator/documents/controlschemes?view=minecraft-bedrock-stable): 가상 스틱과 화면 스와이프를 분리하는 터치 입력의 보조 참고 자료.

게임 화면이나 자산을 복제하지 않고, 지상 운송에 필요한 이동·시점·행동의 분리에 적용했습니다.

## 적용

- 왼쪽 고정 아날로그 스틱: 중앙 12%는 미세한 손 떨림을 무시하며, 나머지 구간은 연속적인 이동 속도를 제공합니다. 대각선과 키보드 혼합 입력도 최대 속도를 넘지 않습니다.
- 오른쪽 화면 드래그: 이동 손가락과 별도의 포인터로 시점을 회전합니다. 한 손을 떼도 다른 손의 조작이 유지됩니다.
- 오른쪽 아래 원형 버튼: 달리기, 짐 잡기, 시점 되돌리기, 상황별 작업. 이동 중 두 번째 손가락으로 누르는 행동은 pointerup으로 처리하고 중복 click은 무시합니다.
- 작업 버튼은 거점 근처에서 적재·휴식·연결로 바뀌며, 거점에서 멀면 비활성 상태로 위치를 유지합니다.
- 스틱을 놓으면 이동과 달리기를 해제합니다. 터치 취소는 해당 포인터를 해제하고, 화면 회전·일시정지·초점 상실은 모든 입력을 해제합니다.
- 일시정지 메뉴에서 시점 감도 50–200% 조정. 별도 설정 키를 사용하므로 궤도 진행 데이터에 영향을 주지 않습니다. 저장소 접근이 제한되어도 현재 세션에서 설정할 수 있습니다.
- 오른쪽 행동 버튼은 최소 52 px, 주 작업 버튼은 80 px입니다. 가로·세로 화면과 안전 영역을 고려해 배치합니다.

## 재현 가능한 확인

`npm test`는 아날로그 데드존·속도·대각선·포인터 소유권과 기존 배송 규칙을 검사합니다.

`npm run test:surface:mobile`은 Chromium의 실제 터치 이벤트로 이동·시점 동시 조작, 손가락별 해제, 이동 중 행동, 취소, 일시정지, 시점 복귀, 감도 저장과 화면 회전을 검사합니다. 320×568, 360×640, 430×932, 640×360, 800×450에서 UI의 화면 이탈과 겹침을 확인합니다. 오프라인 실행과 데스크톱 키보드·메뉴 초점도 함께 확인합니다.

`npm run test:surface`에는 전체 키보드 배송 여정과 같은 모바일 검증이 포함됩니다. 실제 iOS·Android 기기의 성능과 제스처는 별도로 확인해야 합니다.
