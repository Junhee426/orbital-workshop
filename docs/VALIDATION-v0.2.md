# v0.2 검증 기록

검증일: 2026-09-26

- Node.js 24.19.0, Python 3.12, Playwright 1.62.1, Chromium 151.0.7922.34 / SwiftShader.
- 단위 테스트 20개 통과: 3종 수리와 저장 재개, 순차 해제, 중복 보상·구매 방지, 연료·장갑 효과, 양쪽 패널 충돌·접선 속도 보존, 피치 각속도, 튜토리얼, v1 마이그레이션, 불러오기 실패 시 원본 보존.
- 실제 브라우저 키 입력으로 첫 임무 비행·포획부터 진단·수리·작동 시험·보상을 검증.
- 새 임무는 실제 임무 선택으로 출항을 확인한 뒤 정상 시뮬레이션에서 생성한 포획 체크포인트를 파일 불러오기 UI로 적용. 배터리 교체와 안테나 재정렬·시험·보상을 실제 UI 입력으로 완료.
- 손상된 저장의 자동 덮어쓰기 방지, 원본 백업, 잘못된 파일 차단, 정상 파일 미리보기·적용, JSON 내보내기 검증.
- 도움말 포커스 순환·복원과 중첩 일시정지 복원 검증.
- 430×932 터치 에뮬레이션: 이동·멀티터치·미세 모드·회전·실습 안내 숨김·파일 불러오기 검증. 360×640 화면의 가로 넘침과 부품 선택 트레이 위치 검증.
- 최종 실행 파일에서 800×450 가로 화면 터치 패널과 작업 버튼의 비겹침을 추가 검증. 360×640 세로 화면에서 부품 선택, 파일 불러오기, 안내 배치를 재확인.
- PLAY.html을 file:// 주소에서 열어 실행과 모달 동작 검증. 콘솔 오류와 외부 HTTP 요청 없음.

명령: `npm test`, `npm run build`, `npm run test:e2e`.
스크린샷은 git에서 제외한 `test-results/`에 생성됩니다.

한계: 실제 iPhone·Android 기기, 모든 브라우저·GPU 조합, 장시간 플레이와 실제 서버 배포는 검증하지 않았습니다. 물리와 수리 수치는 게임용 모델입니다.
